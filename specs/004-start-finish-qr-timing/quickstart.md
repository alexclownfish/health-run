# Quickstart

1. 使用 `qr-payloads.md` 的五行原文分别生成纯文本 QR。标签中文名称是说明，不要一起编码。三个原任务点码不变，可继续使用。
2. 编译新版小程序，上传新体验版。新进度从起点开始；旧 v2 数据不会迁入或删除。
3. 从小程序内点击起点扫码。任务点或终点码必须拒绝；起点成功后进入路线第一任务点。
4. 依次完成任务 001、002、003 的扫码、动作、照片保存，第三点后进入终点扫码页，不得直接解锁凭证。
5. 扫描 999 终点，显示凭证的完成时间和总用时，保存相册后核对海报时间相同。
6. 重进、取消、拒绝权限、重复扫码、错顺序、页面卸载后的回调均检查；过程中关闭后重开，开始时间不变。
7. 完赛后重进确认结束时间固定。仅“我的 -> 重置本次路线”可开始新一轮测试。

计时是手机时间差，不暂停。微信首页“扫一扫”识别这种纯文本码不会完成打卡，须用小程序内按钮。
