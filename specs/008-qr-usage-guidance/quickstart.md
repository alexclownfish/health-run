# 发布与验收：带提示的五张二维码

1. 安装锁定的电脑开发依赖，运行`npm run generate:qr-tags`。图片及原文位于assets/qr-checkpoints/，完整制作清单位于../004-start-finish-qr-timing/qr-payloads.md。
2. 运行`npm test`，其中实际PNG解码验证中文、LF换行、原点位数据及新版小程序校验。
3. **先重新编译并上传支持新格式的体验版，再更换标牌。**旧体验版会拒绝带提示的新二维码。新版仍支持旧标牌，不需要重置现有进度。
4. 用最新体验版依次扫描起点、任务点1/2/3并完成动作和照片、终点，核对计时、凭证和原完赛摘要。各平台现场扫码效果待真机验收。
5. 用相机、微信扫一扫、支付宝扫一扫检查是否显示指定提示及原文，记录不显示文本的软件；不承诺控制外部软件界面或阻止其解码。标牌旁可印同样提示。
6. 保留二维码白边，不将Logo、文字覆盖在码区；内容增加后码更密，建议码区至少5cm并现场试扫，不代表所有距离和机型均保证识别。

本次二维码提示采用用户指定名称“绿色康跑”；其他页面活动主题保持现有值。云函数submitCompletion、开发环境cloudbase-d2gd1ocuha5342ad6和ACTIVITY_CONFIG均不需要修改或部署，activityId/routeVersion/routeId保持固定。
